Job Description: Backend Developer

Company: TechCorp Solutions
Location: Ha Noi, Vietnam
Employment Type: Full-time

About the Role:
We are looking for a talented Backend Developer to join our engineering team. You will be responsible for designing, developing, and maintaining scalable backend systems that power our platform.

Key Responsibilities:
- Design and develop RESTful APIs that are scalable, maintainable, and follow REST conventions to support our platform's core functionality.
- Write clean, maintainable, and well-tested code
- Optimize database queries and improve system performance
- Collaborate with frontend developers and product teams

Required Qualifications:
- 3+ years of experience in backend development
- Strong proficiency in Python, Java, or Node.js. Candidates should demonstrate hands-on experience with at least one of these languages in production environments, with the ability to write efficient and maintainable code.
- Experience with relational databases (PostgreSQL, MySQL). Candidates must be comfortable with SQL query optimization, database design, and performance tuning to ensure applications run efficiently at scale.
- Familiarity with Git version control
- Strong problem-solving skills and attention to detail

Preferred Qualifications:
- Experience with Docker and Kubernetes for containerization and orchestration
- Knowledge of message queues (RabbitMQ, Kafka) for asynchronous communication
- Experience with AWS or cloud platforms
- Experience with CI/CD pipelines
